# Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The game gets a voice, some movement, plain words for the times something goes wrong, and a home-screen icon.

**Architecture:** A new `client/src/sound.js` owns the audio context, the mute and the vibration, and exports one function per sound. The screens call it; they never touch the Web Audio API themselves. The motion is four CSS transitions, and the `prefers-reduced-motion` rule that already exists finally has something to switch off. A hand-written service worker caches the app's own files on the fly and never the 3.7MB player pool.

**Tech Stack:** Plain ESM JavaScript, no build step, no new dependency. The Web Audio API and the Vibration API, both of which are no-ops where they are not available. `node --test` for the sound module, Playwright for the screens.

**Spec:** `docs/superpowers/specs/2026-10-21-polish-design.md` — read it before starting. It is the authority on behaviour.

---

## Global Constraints

These apply to every task. They are not negotiable without changing the spec first.

- **No sound ever plays before a gesture.** A mobile browser will not make a sound before one, and the first tap both unlocks the context and plays the click.
- **A sound never blocks the game.** If the audio context cannot be created, the game plays on in silence.
- **Sound is never the only feedback.** Every cue is also visible: the clue card appears, the verdict says it, the timer moves.
- **The mute is remembered, in both directions.** A player who muted it once does not get a surprise.
- **Haptics follow the same switch as the sound.** Muting the sound mutes the buzz.
- **The `prefers-reduced-motion` rule is not changed.** It stays as it is, and every transition added is switched off by it.
- **Nothing moves a thing the player is reading.** The clue ladder does not jump; the clue cards arrive in place.
- **Every empty and error state names what happened and offers the next thing.** None of them is a stack trace, a raw id, or a blank screen.
- **The service worker caches the app's own files and never the player pool.** A stale pool is worse than no pool.
- **No player-facing string names a scope, a predicate, a metric, a window id or a raw id.**
- **Node tests:** `npm test`. **Browser tests:** `npm run test:client`.

## Review Focus

Five input classes the spec implies but no task's happy path exercises. Each one gets a test in the task that owns the code.

1. **A browser with no Web Audio at all** — an old browser, or one where the context is blocked. The game must play on in silence, with no error on the screen. → Task 1
2. **A browser with no Vibration API** — every desktop browser. The game must not break and must not log an error. → Task 1
3. **A player who muted the sound and comes back tomorrow** — the mute is remembered, and the game still plays. → Task 2
4. **A second tab opened on the same game** — the mute is shared through storage, and the two tabs do not fight over it. → Task 2
5. **A player whose browser cannot fetch the player pool** — the cards must not sit on an ellipsis forever; the screen must say what happened and offer a way to try again. → Task 4

```js
/**
 * The game's voice.
 *
 * Every sound is synthesised: a short oscillator with a gain envelope.
 * There are no audio files, so there is nothing to download, nothing to
 * license and nothing to lose. A browser with no Web Audio plays on in
 * silence.
 *
 * The mute is remembered, in both directions, and the haptics follow it.
 */

const MUTE_KEY = 'football-trivia-muted';

/** The sounds, each a short shape of tones. */
const VOICES = {
  click: [{ freq: 660, at: 0, len: 0.05, gain: 0.16 }],
  right: [{ freq: 660, at: 0, len: 0.09, gain: 0.18 }, { freq: 990, at: 0.09, len: 0.16, gain: 0.18 }],
  wrong: [{ freq: 220, at: 0, len: 0.22, gain: 0.16, fall: 120 }],
  tick: [{ freq: 1200, at: 0, len: 0.03, gain: 0.1 }],
  reveal: [{ freq: 880, at: 0, len: 0.06, gain: 0.1 }],
};

let context = null;

/** The audio context, created on the first gesture. */
function audio() {
  if (context) return context;
  const Ctor = globalThis.AudioContext ?? globalThis.webkitAudioContext;
  if (!Ctor) return null;
  try {
    context = new Ctor();
  } catch {
    context = null;
  }
  return context;
}

/** Play one voice. A browser with no audio does nothing at all. */
function play(voice) {
  if (isMuted()) return;
  const ctx = audio();
  if (!ctx) return;
  try {
    if (ctx.state === 'suspended') ctx.resume();
    const now = ctx.currentTime;
    for (const tone of voice) {
      const osc = ctx.createOscillator();
      const gain = ctx.createGain();
      osc.type = 'square';
      osc.frequency.setValueAtTime(tone.freq, now + tone.at);
      if (tone.fall) osc.frequency.exponentialRampToValueAtTime(tone.fall, now + tone.at + tone.len);
      gain.gain.setValueAtTime(0.0001, now + tone.at);
      gain.gain.exponentialRampToValueAtTime(tone.gain, now + tone.at + 0.008);
      gain.gain.exponentialRampToValueAtTime(0.0001, now + tone.at + tone.len);
      osc.connect(gain).connect(ctx.destination);
      osc.start(now + tone.at);
      osc.stop(now + tone.at + tone.len + 0.02);
    }
  } catch {
    // A sound that cannot be made is not an error. The game plays on.
  }
}

export const sounds = {
  click: () => play(VOICES.click),
  right: () => play(VOICES.right),
  wrong: () => play(VOICES.wrong),
  tick: () => play(VOICES.tick),
  reveal: () => play(VOICES.reveal),
};

export function isMuted() {
  try {
    return localStorage.getItem(MUTE_KEY) === '1';
  } catch {
    return false;
  }
}

export function setMuted(muted) {
  try {
    localStorage.setItem(MUTE_KEY, muted ? '1' : '0');
  } catch {
    // A browser with no storage still mutes, for this session only.
  }
  try {
    // Another tab on the same game hears about it.
    globalThis.dispatchEvent(new CustomEvent('football-trivia:sound', { detail: { muted } }));
  } catch {
    // No event bus, no problem.
  }
}

export function toggleMute() {
  setMuted(!isMuted());
  return isMuted();
}

/** A short buzz. A browser without vibration does nothing. */
export function haptic(pattern) {
  if (isMuted()) return;
  try {
    globalThis.navigator?.vibrate?.(pattern);
  } catch {
    // No vibration, no problem.
  }
}

/** The button that turns the sound on and off. */
export function soundToggle() {
  const button = document.createElement('button');
  button.className = 'btn btn--icon btn--sound';
  button.type = 'button';
  const label = () => {
    const muted = isMuted();
    button.textContent = muted ? '🔇' : '🔊';
    button.setAttribute('aria-label', muted ? 'Turn sound on' : 'Turn sound off');
    button.setAttribute('title', muted ? 'Sound is off' : 'Sound is on');
    button.setAttribute('aria-pressed', String(muted));
  };
  label();
  button.addEventListener('click', () => {
    toggleMute();
    label();
  });
  globalThis.addEventListener?.('football-trivia:sound', label);
  globalThis.addEventListener?.('storage', label);
  return button;
}
```

function watchErrors(page) {

  /** Fetch the player pool, once. */
  async ensurePool() {
    if (state.pool) return state.pool;
    if (state.poolLoading) return state.poolLoading;
    state.poolLoading = loadPool()
      .then((pool) => {
        state.pool = pool;
        state.registry = pool.registry;
        state.poolError = null;
        notify();
        return pool;
      })
      .catch((err) => {
        state.poolError = 'Could not load the players. Check your connection.';
        notify();
        throw err;
      })
      .finally(() => {
        state.poolLoading = null;
      });
    return state.poolLoading;
  },

  /** Try the pool again, after it failed. */
  async retryPool() {
    state.poolLoading = null;
    state.poolError = null;
    notify();
    try {
      await this.ensurePool();
    } catch {
      // The message is already on the screen.
    }
  },

/**
 * The raster icons, from the SVG.
 *
 * A browser that will not take an SVG icon wants a 192 and a 512 PNG.
 * Chromium can render the SVG and screenshot it, which is all this needs.
 */
import { chromium } from 'playwright';
import { readFile, writeFile } from 'node:fs/promises';

const svg = await readFile(new URL('../client/icons/icon.svg', import.meta.url), 'utf8');
const browser = await chromium.launch({ args: ['--no-sandbox'] });

for (const size of [192, 512]) {
  const page = await browser.newPage({ viewport: { width: size, height: size } });
  await page.setContent(
    `<style>html,body{margin:0;padding:0}svg{display:block;width:${size}px;height:${size}px}</style>${svg}`,
  );
  const png = await page.screenshot({ omitBackground: true });
  await writeFile(new URL(`../client/icons/icon-${size}.png`, import.meta.url), png);
  console.log(`wrote client/icons/icon-${size}.png`);
  await page.close();
}

await browser.close();

- [ ] **Step 6: Write the service worker**

Create `client/sw.js`:

```js
/**
 * The service worker.
 *
 * The app's own files are cached as they are fetched - there is no list
 * to keep in step, and nothing goes stale when a file is renamed. The
 * player pool is never cached: it is 3.7MB and it changes when the data
 * is rebuilt, and a stale pool is worse than no pool.
 */

const VERSION = 'football-trivia-v1';
const SHELL = `${VERSION}-shell`;

self.addEventListener('install', (event) => {
  event.waitUntil(caches.open(SHELL));
  self.skipWaiting();
});

self.addEventListener('activate', (event) => {
  event.waitUntil((async () => {
    const names = await caches.keys();
    await Promise.all(names.filter((n) => n !== SHELL).map((n) => caches.delete(n)));
    await self.clients.claim();
  })());
});

/** The pool is never cached, and neither is anything that is not ours. */
function isCacheable(url) {
  if (url.pathname.includes('/data/fixtures/')) return false;
  if (url.pathname.startsWith('/rest/')) return false;
  if (url.pathname.startsWith('/auth/')) return false;
  if (url.pathname.startsWith('/functions/')) return false;
  return url.origin === self.location.origin;
}

self.addEventListener('fetch', (event) => {
  const request = event.request;
  if (request.method !== 'GET') return;

  const url = new URL(request.url);
  if (!isCacheable(url)) return;

  // The page is fetched from the network first, so a deploy is picked
  // up on the next load. Everything else is served from the cache, so
  // the game opens instantly.
  if (request.mode === 'navigate') {
    event.respondWith((async () => {
      try {
        const fresh = await fetch(request);
        const cache = await caches.open(SHELL);
        cache.put(request, fresh.clone());
        return fresh;
      } catch {
        const cached = await caches.match(request);
        if (cached) return cached;
        return new Response(
          '<!doctype html><meta charset="utf-8"><title>Offline</title>'
          + '<body style="font-family:system-ui;padding:24px">'
          + '<h1>You are offline</h1>'
          + '<p>The game needs a connection to play.</p></body>',
          { status: 503, headers: { 'Content-Type': 'text/html; charset=utf-8' } },
        );
      }
    })());
    return;
  }

  event.respondWith((async () => {
    const cached = await caches.match(request);
    if (cached) return cached;
    const fresh = await fetch(request);
    if (fresh.ok) {
      const cache = await caches.open(SHELL);
      cache.put(request, fresh.clone());
    }
    return fresh;
  })());
});
```

```markdown
# Feel

How the game sounds, moves, and behaves when something goes wrong.

## Sound

Every sound is synthesised in the browser - a short oscillator with a
gain envelope. There are no audio files, so there is nothing to download
and nothing to license.

The speaker button in the topbar turns the sound off. The choice is
remembered, in both directions, and the buzz that goes with it follows
the same switch. A browser with no Web Audio plays on in silence.

Sound is never the only feedback. A clue appears, the verdict says it,
the timer moves.

## Movement

Four small transitions: a clue arrives in place, a button presses in,
the verdict pulses, the screen fades in. A player who has asked their
system for less movement gets none of it - the rule is in
`client/styles/app.css` and it applies to everything.

## When something goes wrong

Every screen says what happened and offers the next thing. The pool not
loading is the one that matters: the screen says so and offers a way to
try again, rather than leaving an ellipsis on the cards forever.

## On your home screen

The game has a manifest, an icon and a service worker, so it can be
added to the home screen and opens instantly. The service worker caches
the app's own files as they are fetched - there is no list to keep in
step. The player pool is never cached, and the game still needs a
connection to play.
```
